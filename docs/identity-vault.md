# 本地身份保险库（学 CCBaga · 尽量不改宿主）

> 决策日：2026-11-11（Asia/Tokyo）  
> 决策者：和零（先采纳 [liseami/CCBaga](https://github.com/liseami/CCBaga) 伴生指纹浏览器，随后明确 **身份保险库也学**，同时 **尽可能避免修改宿主环境**）  
> 状态：**已在云电脑落地（P9，dry-run）**；与 [companion-fingerprint-browser.md](./companion-fingerprint-browser.md) 配套。真机上的活体 Desktop 登录态与进程结束仍须在 Win11 上核验。

## 学什么

参考 CCBaga 的本地身份保险库，而不是它的「改本机时区 / 语言 / 地区」：

- 把 **Claude Desktop（及若存在的 Claude Code）本地身份**做成可归档、可切换、失败可回滚的快照（加密容器 + 目录清单）。
- 切换前先礼貌结束相关 Claude 进程（与 [kill-on-local-ip-change.md](./kill-on-local-ip-change.md) 同一节奏：先关窗口，短超时后再强杀）。
- 登录态始终跟随身份；Skills / 插件 / MCP / 设置 / 会话历史 / 缓存由用户选择「留在工作区」还是「随身份走」。
- 不扫描实际项目源码目录。
- 保险库与 Claude 工作目录分开；可与伴生指纹浏览器的独立 profile 绑定（换身份时换浏览器资料，仍不走宿主默认浏览器）。

这是 **盒子内的本地快照**，不是服务端身份，也不能保证账号在 Anthropic 侧仍然有效。

## 硬约束：尽可能不改宿主

| 要避开的宿主改动 | 约定 |
|------------------|------|
| 时区 / 语言 / 地区 | **不改**宿主 Win11（仍东八区 + 简中） |
| 默认浏览器、系统代理、全局环境变量 | **不改** |
| 宿主日常 Claude 安装与 `%APPDATA%\Claude` 等默认目录 | **不作为**保险库工作副本；盒子用发行版内 / `ClaudeBox` 专属数据根 |
| 宿主凭据库（Windows 凭据管理器、本机钥匙串） | **尽量不写**；优先发行版内文件凭据。若某次恢复非写宿主不可，必须明示，并只写 Claude Box 自己的条目 |
| 宿主用户主目录其它软件资料 | 不扫描、不搬移 |

保险库落点（规划）：

- WSL 主轨：发行版内路径，例如 `/var/lib/claude-box/identity-vault`（或发行版用户下的等价目录）。
- 若宿主需要一份索引：仅 `%LOCALAPPDATA%\ClaudeBox\identity-vault\`（Claude Box 自己的目录），**不要**写进用户默认 Claude / 浏览器资料。
- 云电脑 dry-run：`<repo>/.run/claude-box/identity-vault`（gitignore）。

同用户下的其它程序仍可能读到这些文件（CCBaga 也声明保险库不是对同用户程序的隔离边界）；隔离靠盒子目录 + 权限，不靠改系统。

## 实现落点（P9）

C++ 核心 `claudebox::vault` 与设置页「身份保险库」、命令行 `claudebox-vault` 已接线。云电脑上归档 / 切换 / 回滚对盒子前缀内的夹具身份有效。进程结束只做 dry-run。

| 项 | 约定 |
|----|------|
| 容器 | AES-256-GCM + PBKDF2-HMAC-SHA256（OpenSSL 3，200000 次）；不必与 CCBaga `.baga` 二进制兼容。口令来自 `CLAUDE_BOX_VAULT_PASSPHRASE_FILE` 或环境变量，不写日志。 |
| 事务 | 切换前先写一份同身份的 pre-switch 安全归档（该归档可能成为当前指针），再尝试切到目标并校验。强制失败时，失败的目标代次不会成为当前身份，工作副本也不会切到失败目标。中断可恢复。 |
| 进程 | 切换 / 备份前结束盒子内 Claude（及已绑定的伴生浏览器），不杀宿主其它软件 |
| 伴生浏览器 | 每个已绑定身份使用独立 `user-data-dir`；资料放在盒子侧，不并进宿主 Chrome/Edge |
| 导出 / 导入 | 可后做；密码包不得经聊天或日志明文出现 |

桩目录：`src/wsl-box/identity-vault/`（W7 接线）。

## 验收（W7 / P9）

云电脑已证明：归档当前夹具身份、切到空工作区再切回；强制失败时失败的目标不会成为当前身份（切换前同身份的安全归档可能成为当前指针），工作副本不会切到失败目标；写入不离开盒子前缀；口令不出现在状态文本。真机上「登录资料按策略恢复、切换时结束活的 Desktop / 伴生浏览器」仍待 Win11 核验。


- 归档当前盒子身份、切到空工作区、再切回：登录资料按策略恢复，失败能回滚。
- 全程 **不**改变宿主时区、语言、默认浏览器、系统代理。
- 不改写宿主默认 Claude 用户目录（除非用户将来明确授权「导入宿主已有身份」，且仍复制到盒子内，而不是原地改宿主）。
- 切换时伴生浏览器跟身份走（若已启用 OA 策略）；OAuth 仍不落到宿主默认浏览器。

## 与 CCBaga 的边界

| | CCBaga | Claude Box |
|--|--------|------------|
| 保险库 | 管理本机默认 Claude 目录 | **只管理盒子内**的 Desktop/Code 资料 |
| 系统设置 | 可改本机时区语言地区 | **不改宿主** |
| 伴生浏览器 | 跟身份绑定、核验环境 | 同样可绑定；**另用于 OA 跳转**，防宿主浏览器泄漏 |
