# Claude Box

Docker-like 容器，用于隔离运行 Claude Desktop。

## 目标

在容器里跑 Claude Desktop：项目目录可挂入，其它宿主机文件默认不可见；出入网经 Docker 管理的唯一网关；原生 GUI 窗口透出；尽量伪装完整独立环境并拦截对环境的遥测。

## 平台

- 优先：Windows 11
- 其次：macOS
